# **App Name**: WelfareWise

## Core Features:

- Member Profile Management: Add, update, and manage member profiles with detailed information.
- Contribution Tracking: Record and track individual monthly contributions via paybill.
- Contribution Viewer: View individual contribution history.
- Welfare Request Processing: Process welfare requests, track their status, and manage disbursements.
- Fund Balance Monitoring: Monitor the overall fund balance with detailed transaction logs.
- Generate Contribution Summary: Summarize and list monthly contributions and display them clearly.
- Anomaly detection in Contributions: Employ AI to flag unusual contribution patterns or discrepancies. This tool identifies significant deviations that require admin review, using historical data as a baseline.

## Style Guidelines:

- Primary color: Professional navy blue (#192A56) to convey trust and stability.
- Background color: Clean, desaturated light blue (#E5E9F2) to ensure clarity and readability.
- Accent color: A slightly brighter, analogous blue (#4A6499) to highlight key actions and information.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a neutral look, is good for headlines or body text.
- Use simple, professional icons to represent different functions and data categories.
- Maintain a clean and organized layout with clear visual hierarchy for easy navigation.
- Use subtle animations for transitions and feedback to enhance user experience.
